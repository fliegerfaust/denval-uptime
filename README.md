# denval-uptime

Внешняя проверка, что `denvalclass.ru` жив.

Раз в 15 минут GitHub Actions дёргает `https://denvalclass.ru/api/health` и, если
ответ не `{"ok":true}`, пишет Денису Валерьевичу в Telegram через бота
`@DenValNauchit_Bot`. Когда сайт поднимается — пишет об этом же.

**Почему это отдельный публичный репозиторий, а не рабочий `denval-class`:**

- **не тот же сервер.** Проверка обязана жить снаружи: пинг с самой машины
  умрёт вместе с тем, за чем следит, и о падении Денис узнает от ученика;
- **не приватный репозиторий.** У приватных бесплатны 2000 минут Actions в
  месяц, а проверка каждые 15 минут съедает около 2900 — пришлось бы платить
  GitHub вместо сервиса мониторинга. У публичных Actions бесплатны без лимита.

Здесь нет ни кода продукта, ни данных. Токен бота и chat_id лежат в секретах
репозитория (`TG_BOT_TOKEN`, `TG_CHAT_ID`), в файлах их нет.

Файл `state.txt` — память между запусками: сообщение уходит только на СМЕНЕ
состояния, иначе за ночь падения набежало бы под сорок одинаковых.
